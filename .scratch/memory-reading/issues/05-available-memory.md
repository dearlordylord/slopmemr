## Question

Что возвращает чтение, пока новая память ещё суммаризируется?

## Comments

Пользователь ответил в живом обсуждении: фоновая обработка должна работать, но агент получает уже имеющуюся память со статусом обновления/свежести. При отсутствии готовой памяти получает пустую память и статус. Незавершённая обработка сама по себе не ошибка.

## Answer

Возвращать доступную сводку и фактическое покрытие вместе со статусом; не скрывать готовый префикс из-за незавершённого хвоста. При нулевом готовом покрытии возвращать пустой текст со статусом. Фоновая компакция продолжается без ожидания в запросе чтения.

Ошибка провайдера не должна скрывать уже доступную память: показывать её и состояние обработки. Это решение не обещает успех при недоступном резиденте, нечитабельном хранилище или неверном запросе.

Точные поля свежести, названия статусов и контракт zoom остаются в [Контракте чтения памяти для агента](02-reading-contract.md).
