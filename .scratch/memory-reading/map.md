# Чтение памяти агентом через MCP и CLI

Label: wayfinder:map
Status: complete — implementation and acceptance recorded in docs/validation/memory-reading-review.md

## Destination

Согласованная спецификация чтения памяти через MCP того же резидента и CLI, с короткой инструкцией в отдельном быстром хуке, установкой и обслуживанием. Карта заканчивается спецификацией; реализация идёт отдельным этапом.

## Notes

- Wayfinder: сначала решения, без продолжения реализации.
- Пользователь уже определил: Effect 4, практики hulymcp, семантика UNII, консультация Астры, пример хука ponytail.
- Ответы пользователю короткие; технические детали остаются в тикетах.
- Использовать wayfinder, grilling, domain-modeling; исследования через research, реализация позднее через effect.
- Трекер проекта не настроен: временно используется локальный Markdown по умолчанию wayfinder. Для постоянной настройки предусмотрен `/setup-matt-pocock-skills`.
- Реализация и приёмка завершены, изменения закоммичены в master. Выпуск готового Linux arm64 пакета — v0.1.0; другие платформы требуют отдельных проверок.

## Decisions so far

- [Контракт чтения памяти для агента](issues/02-reading-contract.md#answer): доступный префикс и частичный zoom со статусом/датами, прямые MCP-схемы и маленькая инструкция SessionStart; контракт собран в спецификации.

- [Быстрый standalone hook](issues/08-fast-hook.md#answer): нужен отдельный hook artifact и граница реального entry/build/launcher; предложены warm/fresh latency budgets, измерен только безопасный общий CLI `--help` baseline.

- [Подключение MCP к Claude и Codex](issues/03-mcp-installation.md#answer): автоматическая регистрация, готовый пакет со встроенным runtime и немедленное корректное переключение резидента после update; память сохраняется.

- [Установочный CLI и обслуживание по образцу hapsland](issues/07-install-maintenance.md#answer): подтверждены разделение пакета, регистрации и serving resident и пробелы текущего update; продуктовый выбор хранится в тикете подключения MCP.

- [Discoverability MCP по образцу hulymcp](issues/06-tool-discovery.md): исследован proxy-подход; пользователь выбрал прямые инструменты с полными схемами, без поиска и proxy-вызовов.

- [Доступная память во время обновления](issues/05-available-memory.md): возвращать имеющуюся сводку со статусом, при её отсутствии — пустую память; фоновую компакцию не ждать.

- [Семантика чтения UNII и ограничения транспорта](issues/01-reading-semantics.md#answer): подтверждены exclusive before, готовность префикса, бинарный zoom/страницы, lazy-open и образцы Effect MCP/SessionStart.

## Out of scope

- Автоматическая подача snapshot в контекст.
- Релевантный подбор памяти и управление бюджетом контекста.
- Изменение аутентификации суммаризатора, удаление памяти или новые административные MCP-инструменты.
