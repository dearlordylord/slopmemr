# Issue tracker

Provider: GitHub Issues
Repository: https://github.com/dearlordylord/slopmemr
Authority: user instruction to keep all task planning in the GitHub repository.

Store tasks, plans, dependencies and completion status in GitHub Issues. Create or update the issue before starting newly planned work. Use `gh issue` with the explicit repository `dearlordylord/slopmemr`; preserve completed work as closed issues and pending work as open issues. Put multiline bodies in a file and pass `--body-file`.

When migrating existing local plans, verify the remote issue bodies and states before removing their local copies. Link implementation commits and acceptance evidence when closing work. Product contracts, research findings and validation artifacts remain repository documentation under docs.
